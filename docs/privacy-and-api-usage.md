# 개인정보 및 외부 AI 이용 안내

## 화면과 OCR

화면 또는 게임 창에서 지정한 영역을 PC에서 캡처하고, 앱에 포함된 OCR 모델로 글자를 읽습니다. 이미지를 열면 그 이미지도 PC의 OCR로 처리합니다. 클립보드 모드에서는 화면 대신 클립보드 텍스트를 사용합니다. 번역·해설 제공자에 보내는 것은 OCR이나 클립보드에서 얻은 **텍스트**입니다. 번역 및 해설 요청에는 캡처 이미지 파일을 첨부하지 않습니다.

## 선택한 제공자에 전달되는 내용

| 제공자 | 번역·해설 요청 | 비용 |
| --- | --- | --- |
| 내장 로컬 AI (Hy-MT2) | 현재 원문과 사용할 문맥·캐릭터 정보는 PC의 로컬 프로세스에서 처리합니다. 모델이 없을 때 사용자가 설치에 동의하면 Hugging Face에서 모델을 내려받고 무결성을 검사합니다. | 번역 API 사용료 없이 PC 자원과 다운로드 네트워크를 사용합니다. |
| OpenAI | 모델 ID, 번역 지시문, 현재 원문, 사용 가능한 문맥과 사전 정보가 OpenAI API로 전달됩니다. 문장 해설 요청에는 선택한 원문과 해설용 지시가 포함됩니다. 앱은 Responses API에 `store: false`를 요청합니다. 처리 및 보존 조건은 계정과 제공자의 데이터 정책을 확인하세요. | 모델과 입력·출력 토큰 등에 따라 달라집니다. [OpenAI API 요금](https://platform.openai.com/pricing/) |
| Gemini | 모델 ID, 번역 지시문, 현재 원문, 사용 가능한 문맥과 사전 정보가 Google Gemini API로 전달됩니다. 해설을 요청하면 원문과 해설용 지시를 보냅니다. | 모델과 무료·유료 등급에 따라 달라집니다. [Gemini API 요금](https://ai.google.dev/gemini-api/docs/pricing) |
| Ollama | 설정한 서버 주소를 사용합니다. 기본 주소는 `http://localhost:11434`입니다. Chat은 원문·지시문과 적용된 문맥·사전을, TranslateGemma 요청 형식은 원문과 언어를 보냅니다. 원격 서버를 지정하면 해당 서버에서 요청을 처리합니다. | 자기 PC에서 실행하면 PC 자원을 사용하며, 원격 호스팅은 운영자가 정한 비용이 발생할 수 있습니다. |
| DeepL | 영어·일본어 원문, 언어 코드, 사용 가능한 이전 **원문**을 선택한 Free 또는 Pro API로 보냅니다. 캐릭터 사전과 문장 해설은 지원하지 않습니다. | 문자 사용량과 요금제에 따릅니다. [DeepL API 요금제](https://www.deepl.com/pro-api) |

문맥은 현재 게임 프로필의 번역 세션에서 재사용합니다. 해당 제공자가 문맥을 지원하고 요청에 사용할 기록이 있을 때 이전 원문과 번역이 포함될 수 있습니다. 캐릭터 사전은 해당 프로필에서 사용을 켜고 읽을 수 있는 JSON을 지정한 경우, 이를 지원하는 방식의 번역에 캐릭터 정보가 포함될 수 있습니다. OpenAI와 Gemini는 모델 목록 조회를 요청할 때 API 키를 사용합니다. 자막의 단어 사전을 직접 열면 선택한 원문 단어가 설정된 사전 사이트의 검색어로 전달됩니다.

## PC에 저장되는 데이터

- Windows의 `%LOCALAPPDATA%/KoTrans2`에 설정·프로필·일부 진단 정보가 저장됩니다. 버전을 바꿔 실행할 때 기존 설정 백업이 만들어질 수 있습니다. 게임 경로나 사용자 사전 경로가 설정에 포함될 수 있습니다.
- OpenAI·Gemini·DeepL API 키는 제공자별 파일에 Windows DPAPI CurrentUser로 암호화해 저장합니다. 설정 JSON에 키를 평문으로 저장하지 않습니다. API 요청 시 자격증명은 해당 제공자에게 인증에 사용됩니다. 다른 PC나 Windows 계정에서는 키를 다시 등록하세요.
- 현재 소스에서 일반 번역의 OCR 원문·번역 기록은 세션 메모리에 보관합니다. 옵션을 켜면 인식 원문을 Windows 클립보드로 복사할 수 있으므로 클립보드 기록·장치 간 동기화 설정에 유의하세요. 개발용 진단 자료를 명시적으로 저장하면 일부 경로에서 이미지·인식 결과·진단 정보가 로컬 파일에 남을 수 있습니다.
- 확인한 앱 소스에는 일반 번역 중 캡처 이미지를 자동 업로드하거나 앱 자체 사용 통계를 전송하는 코드가 없습니다. 번역·해설·모델 설치·외부 사전의 통신은 위 조건과 각 서비스의 정책을 따릅니다. 선택형 OCR GPU 가속에 사용하는 Microsoft DirectML에는 Microsoft 자체 데이터 수집 조항이 있습니다. [Microsoft 개인정보처리방침](https://www.microsoft.com/privacy/privacystatement)

계정명, 채팅, 실명 등 개인정보가 대사와 겹치면 해당 부분을 OCR 영역에서 빼고, 민감한 화면에는 내장 로컬 AI를 사용하세요. 문제를 공유할 때는 원문, 화면, 설정 파일, 로그, 키를 보내기 전에 민감한 정보를 가리거나 합성 예시로 바꾸세요.
