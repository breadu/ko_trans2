# 둘째 줄 누락과 제한된 위치 보완 검증 — 2026-11-15

기존 `codex/match-dialog-buttons` 브랜치의 `949af20` 이후 변경이다. 새 브랜치나 프로젝트 복사본을 만들지 않았다. main 병합과 Push는 하지 않는다. 녹화 모드 및 배포 구조, 모델, Local AI, OpenCV, 버전 번호는 유지한다.

## 원인과 현재 화면 우선 판정

사용자가 멈춰 둔 장면을 실제 설정 영역으로 캡처했다. 1397×278 픽셀 안에 두 줄이 모두 있었다. v6 검출기는 첫 줄 앞쪽의 괄호·말줄임표를 놓쳐 첫 줄 시작점을 뒤로 잡았다. 두 검출 줄의 시작점 차이 82px가 기존 허용값인 첫 줄 높이 44px를 넘으면서, 둘째 줄이 문자 인식 전에 제외됐다. CPU와 실제 DirectML에서 동일하게 재현됐다.

기준 줄보다 조금 앞에서 시작하는 인접 줄에 한해, 시작점 차이 최대 글자 높이의 2배 및 짧은 줄 폭의 절반 이상 겹침을 허용했다. 글자 높이·별도 기준선·줄 간격 조건은 유지한다. 뒤로 들어간 짧은 배경 라벨에 대한 기존 제한도 유지한다. 게임명이나 특정 영문자·숫자를 판정 조건에 사용하지 않는다. 같은 구현을 세 모델과 CPU/GPU에서 공유한다.

## 이전 위치는 보완 근거로만 사용

- 번역 세션별 메모리에 최근 15초 이내의 높은 인식 신뢰도(0.9 이상)를 가진 2~4개 줄 위치만 보관한다. 이전 문장이나 이미지는 이 기능에 저장하지 않는다. 설정/프로필 파일에도 저장하지 않는다.
- 현재 검출기에 실제로 잡힌 후보 줄만 보완할 수 있다. 검출되지 않은 줄을 만들어 내거나 이전 텍스트를 출력하지 않는다. 현재 기준 줄과 후보 줄의 높이·기준선·시작점·간격·가로 겹침을 함께 비교한다.
- 보완 후보와 현재 기준 줄 모두 이번 인식의 신뢰도가 0.85 이상이어야 한다. 기준 줄은 과거 위치의 도움 없이 인식되어야 한다. 이 값은 정확도 보증이 아니라 추가 제한이다.
- 위치가 바뀌거나 화면이 비면 이력을 버린다. 캡처 크기/모델/지원 방식 변경 및 세션 종료 시 초기화한다. 프로필별 새 파이프라인에 다른 프로필의 이력을 전달하지 않는다.
- 보완된 결과와 결과 캐시의 재사용은 이력의 유효 시간을 연장하지 않는다. 잘못된 추정이 스스로 계속 강화되지 않는다.
- 수동·강제 재인식 및 신선한 원문 확인 요청은 이력 없이 판정한다. 부분 영역 탐색에 전체 화면 좌표를 전달하지 않는다. NVL/세로/영어는 이 보완을 사용하지 않는다.
- CPU/GPU 요청과 정확한 QA 재현에 동일한 위치 정보를 전달한다. 결과 캐시 키에도 위치 정보를 포함한다. 알고리즘을 v25로 구분하고, v24 자료는 명시적인 현재 알고리즘 비교만 허용한다.

저장된 위치 재판정은 2,199건을 새 모델 추론으로 재실행한 결과가 아니다. 과거에 제외한 배경 영역이 이번 조건 변경으로 다시 선택되는지를 검사했다. 시각 순서가 없는 자료에는 이력을 연결하지 않았다. 이력으로 모호한 현재 둘째 줄을 살리는 양성 사례, 검출 없음, 이동한 기준 줄, 작은 라벨, 낮은 신뢰도, 15초 만료, 캐시/보완의 자기 갱신 방지, 크기/모델/세션 초기화는 합성 입력으로 검증했다. 실제 새 연속 플레이의 모든 배치를 검증했다는 의미는 아니다.

실제 문제 캡처는 기존 v6에서 1줄, 수정 후 2줄이었다. v5와 혼합 모델은 수정 전후 모두 2줄이었다. GPU는 RTX 5070 Ti의 DirectML 실행이며 CPU fallback이 아니었다. 둘째 줄은 캡처 이미지와 직접 대조했다. 현재 장면의 복구에는 과거 위치가 필요하지 않다.

| 모델 | 수정 후 CPU | 수정 후 DirectML |
| --- | --- | --- |
| v6 Medium | 268~305ms | 74ms |
| v5 | 83~85ms | 67~68ms |
| v5 검출 + v6 인식 | 167~190ms | 67~68ms |

모델 로딩을 포함한 첫 실행을 제외한 각 2회 측정이며 인식 캐시를 우회했다. 성능 벤치마크가 아닌 해당 프레임의 진단값이다. v6의 수정 전에는 둘째 줄 인식 자체가 생략됐으므로 수정 후 추가 인식 비용이 발생한다. 과거 위치 비교를 위해 추가 캡처나 검출 모델 실행을 하지 않는다.

## 범위와 남은 확인

이전 위치를 100% 신뢰하지 않는다. 새 게임/배경에서 고신뢰 오인식이 발생할 가능성은 남으며, 이력은 현재 관측의 제한적인 보조 정보다. 실제 위치가 수시로 바뀌는 게임의 새 연속 플레이는 추가 사용자 검증 대상이다. 이번 실제 장면에서 v6가 첫 줄 앞쪽 괄호·말줄임표를 검출하지 못한 현상은 남아 있으며, 이를 게임별 문자열 보정으로 감추지 않았다.

유료 AI 호출, 사용자 설정 변경, 게임 조작은 하지 않았다. 원본 게임 이미지·대사·진단 자료는 저장소 밖의 로컬 검증 폴더에만 유지한다. 테스트 코드에는 합성 문장과 좌표만 넣었다. 별도 테스트 ZIP은 이 변경을 커밋한 소스에서 생성하며 기존 ZIP은 보존한다.
