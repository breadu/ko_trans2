# 앱 삽화 출처 및 사용 범위

프로젝트 소유자는 아래 삽화 세 종류를 ChatGPT의 이미지 생성 기능으로 만들었다고 확인했다. 확인 근거는 이번 작업 요청의 소유자 진술이다. 원본 대화, 생성 프롬프트·날짜, 작업 전의 원본 이미지 파일은 검토하지 않았다.

| 삽화 | 저장소 파일 | 확인된 제작·후처리 |
| --- | --- | --- |
| KO Trans 2 앱 아이콘 | `src/KoTrans.App/Assets/kotrans-app-icon.png`, `kotrans-app-icon.ico` | 사용자가 선택한 고양이 이미지. PNG 투명 배경과 256px 축소, 탐색기·작업표시줄용 다중 크기 ICO 변환. |
| 메인 창 고양이 마스코트 | `src/KoTrans.App/Assets/translation-mascot.png` | 사용자가 선택한 고해상도 투명 PNG. |
| 개발자 후원 커피 고양이 | `src/KoTrans.App/Assets/developer-coffee-cat.png` | 프로젝트 소유자가 ChatGPT에서 생성한 이미지. 작업 전 파일과 추가 변환 내역은 미확인이다. |

프로젝트의 사용 범위는 앱 내부 UI 및 EXE 아이콘, 프로젝트 GitHub의 소스 자산과 사용 설명용 스크린샷, 같은 앱을 배포하는 ZIP의 리소스다. 위 삽화에는 프로젝트 코드의 MIT 라이선스를 적용하지 않는다. 독립적인 재사용 허락은 프로젝트 소유자에게 확인한다.

OpenAI 개인용 이용약관의 Content 조항은 적용 법률이 허용하는 범위에서 OpenAI와 사용자 사이의 결과물 권리 귀속을 정하며, 결과물이 고유하지 않을 수 있음을 안내한다. 프로젝트 소유자가 확인한 생성 경위와 이 조항을 앱의 사용 근거로 기록한다. 약관 적용 유형, 제3자 입력·권리 및 법적 저작권 귀속은 별도로 판단할 사항이다. [OpenAI 이용약관](https://openai.com/policies/terms-of-use/)

**NEEDS REVIEW** 현재 사용 근거는 소유자 확인과 저장소 기록이다. 객관적인 생성 이력을 추가로 요구하는 경우 원본 대화 자료 및 입력 이미지의 출처 확인이 필요하다.
