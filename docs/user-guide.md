# KO Trans 2 사용 안내

이 문서는 Windows용 KO Trans 2 폴더 패키지의 사용 안내다. 메인 화면의 **도움말**에서 화면과 함께 읽을 수 있다.

## 실행과 설정

상태표시줄 오른쪽에는 실행 파일의 버전이 표시된다(예: **Ver 1.0**). 마우스를 올리면 전체 빌드 버전을 확인할 수 있다. 긴 상태 메시지는 줄여 표시되지만 툴팁으로 전체 내용을 볼 수 있다.

**프로필 설정 → 캡처 · OCR → OCR GPU 가속 사용 (DirectML)**을 켜면 지원되는 PaddleOCR 모델을 GPU로 실행한다. 기본값은 꺼짐이며 게임 프로필마다 저장한다. 기존 고속, v6 Medium 검출·인식, v5 검출 + v6 Medium 인식을 지원한다. GPU 옵션을 켜거나 끄면 실행 중인 번역을 중지한다. 다시 **시작**을 누르면 변경한 설정을 적용하며 앱 재실행은 필요 없다. GPU 준비·실행 상태는 설정창 하단에 표시한다. GPU 실패 시 한 번 안내하고 CPU로 자동 전환해 번역을 계속하며, 다음 번역 시작 때 GPU를 다시 시도한다. CUDA·Python·별도 SDK 설치는 필요 없다. 배포 폴더의 `ocr-worker`도 함께 유지한다.

Windows x64용 압축 파일을 모두 같은 폴더에 풀고 **KoTrans2.exe**를 실행한다. EXE만 따로 옮기지 않는다. models·IpaDic·DLL·licenses 폴더가 함께 있어야 한다. Python, pip, .NET SDK, FastAPI, Qt, CUDA를 설치하는 방식이 아니다. 첫 OCR과 첫 일본어 읽기에서 필요한 모델/사전을 준비하며, 앱 시작 시에는 읽지 않는다.

설정과 API 키는 설치 폴더가 아닌 `%LOCALAPPDATA%/KoTrans2`에 저장한다. 키는 현재 Windows 계정에 묶인 DPAPI로 보호한다. 다른 계정에서는 다시 등록한다. 설정 파일이 손상되면 원본을 보존하므로 파일을 백업한 뒤 복구한다.

## 게임 번역

메인 화면 오른쪽 고양이 카드의 **마음에 들었다면, 개발자에게 커피 한 잔**을 누르면 자발적 후원 안내가 열린다. 후원 여부와 관계없이 모든 기능을 동일하게 사용할 수 있다. 후원 페이지는 안내창에서 별도로 **후원 페이지 열기**를 눌렀을 때만 기본 브라우저에서 열린다. 현재는 사용자가 발급한 카카오페이 HTTPS 코드송금 링크를 연결했으며, 링크가 설정되지 않았거나 유효하지 않으면 **후원 페이지 준비 중입니다.**라고 표시한다. 후원 안내창의 커피잔을 든 고양이 일러스트는 앱에 내장된 투명 PNG이며, 외부 이미지를 다운로드하지 않는다.

처음 설정한다면 메인 화면 게임 번역 카드 아래의 **? 처음 사용하기**를 누른다. 게임 프로필·언어 → 게임 창 연결 → 대사 영역 → 번역 서비스 → 번역 시작 → 첫 한국어 자막의 6단계를 안내한다. 게임을 진행해 대사가 나온 뒤 영역을 지정해야 하며, 기존 설정은 재사용한다. 안내 창은 최소화하거나 닫아도 되고, 이미 시작한 번역은 계속된다. 자세한 화면은 메인 화면의 **도움말 → 빠른 시작**에서 확인한다.

1. 프로필을 만들고 **영어/일본어**, **일반/노벨**, 일본어에서 필요하면 **세로쓰기**를 선택한다. 일반은 대사 중심, 노벨은 누적된 여러 문단 중심이다. 영어에서는 세로쓰기를 숨기고 OCR에는 적용하지 않지만 체크 값은 보존한다.
2. **프로필 → 번역 서비스**에서 Gemini/OpenAI/Ollama와 사용할 모델을 지정한다. 모델 ID는 제공자별로 기억하며 제공자를 바꾸면 저장한 ID로 전환된다. 처음 지정하는 제공자는 해당 ID를 입력한다. Gemini/OpenAI 키는 **기본 프로필**에서 한 번 등록하며 모든 게임에서 함께 사용한다. 일반 프로필에는 키·전역 단축키 편집 영역이 표시되지 않는다. Ollama 주소는 게임별로 지정한다. 모델은 임의로 변경되지 않는다. 외부 서비스는 별도 이용 조건과 비용이 적용될 수 있다.
3. **캡처 대상**에서 **화면 영역**, **게임 창**, **클립보드** 중 하나를 선택한다. 창 모드는 최초에 게임 창을 선택하면 다음 프로필 선택/시작 시 같은 실행 파일·클래스·제목의 창을 자동 연결한다. 일치하는 창이 없거나 여러 개면 직접 선택한다. 같은 창을 다시 선택해도 대사 영역은 보존한다. 창이 작아져 영역이 맞지 않으면 재지정 안내를 따른다. 대사 영역을 좁게 지정하면 불필요한 UI 글자와 배경을 줄일 수 있다.
4. **번역 시작** 또는 기본 **Shift+F1**로 시작한다.
5. 메인창 **X**로 알림 영역에 숨겨 게임으로 돌아간다. 기본 **F1**, 알림 영역 아이콘의 **열기**, 또는 앱을 다시 실행하여 기존 창을 복원한다. 완전 종료는 아이콘 우클릭 → **종료**를 선택한다. 단축키 충돌은 공통 설정에서 변경한다.
6. 번역 오버레이는 별도의 편집 버튼 없이 테두리·모서리로 크기를 바꾼다. **게임에 클릭 전달** 체크박스를 켜면 본문 클릭을 게임으로 전달하고 왼쪽 위 핸들로 창을 이동한다. 끄면 핸들을 숨기고 본문 내부 드래그로 이동한다. 체크 상태는 게임 프로필마다 저장·복원한다. 자막창과 설정창의 체크박스는 서로 동기화된다. 오른쪽 위 **×**를 누르면 자막창을 닫고 진행 중 OCR·자동 번역을 중지한다. 다시 창을 열어도 자동으로 번역을 재개하지 않는다. 설정창의 **영어·일본어 원문**과 **한국어 번역**에서 각각 글자 크기 슬라이더와 색상을 조절한다. 색상은 기존 3개 기본색에서 고르거나 옆의 **🎨** 버튼으로 Windows 색상 선택창을 열어 임의의 RGB 색상을 선택한다. 버튼 배경은 현재 색을 보여준다. 취소하면 바뀌지 않는다. 원문/번역의 크기·색은 각 게임 프로필에 저장하며, **설정 저장**, 프로필 전환 또는 정상 종료 후 복원한다. 색상 선택창에서 확인한 색은 즉시 저장한다. 옛 설정의 원문은 기존 크기 15·밝은 회색으로 유지한다. 원문 표시·투명도도 조절할 수 있다. 원문 표시를 켜면 OCR 문장의 안정 확인을 마친 뒤 번역 요청 직전에 확정 원문을 먼저 표시한다. 확인 중인 후보는 표시하지 않으며, 번역은 응답을 받은 뒤 갱신된다. 번역 대기 중에는 이전 번역을 유지한다.

지정한 영역을 먼저 캡처한 뒤 입력 이미지의 사방에 16px 가상 배경 여백을 붙여 OCR을 한 번 수행한다. 캡처 범위는 넓히지 않으며 결과 좌표와 Game QA의 input.png는 원래 캡처 기준이다. 일본어 가로 줄의 밝은 끝 글자·문장부호는 바로 이어진 경우에만 인식 범위를 소폭 보완한다. 실제 캡처 밖으로 잘린 글자는 복구할 수 없으며, 일부 한자·긴 대시 등 모델의 오인식은 남을 수 있다.

화면이 안정된 뒤 OCR과 번역을 수행한다. 타자기식 대사 중간에는 기다린다. 같은 화면/문장의 불필요한 요청을 줄이며, 연결 실패나 timeout을 무조건 재전송하지 않는다. 문맥 초기화는 현재 프로필에 적용된다.

기본적으로 자주 사용하는 **게임 캡처**와 **OCR 모델·GPU 가속**만 **캡처 · OCR** 페이지에 표시한다. 클립보드 결과 복사, Magpie 확대 중 원본 게임 화면 캡처, **문장 끝 표시 학습 초기화**는 **캐릭터 사전 아래의 고급 설정**에 모아 두었다. 문장 끝 표시 학습은 지원되는 게임에서 자동으로 실행되며, 잘못 학습됐을 때만 해당 게임·OCR 모델의 데이터를 확인 후 초기화한다. 초기화하면 번역이 중지되며 다음 시작부터 다시 학습한다.

### OCR 모델 선택 기준

OCR 모델 콤보박스에는 다음 특징을 표시한다. 정확도·처리 속도는 **일반적인 선택 기준**이며, 실제 결과는 게임 글꼴·화면 품질·PC 성능 및 설치된 v5 모델 구성에 따라 달라질 수 있다.

| 모델 표시명 | 사용 기준 |
| --- | --- |
| PaddleOCR v6 Medium (기본 · 정확도 우선) | 작은 글자나 복잡한 글꼴을 더 정확하게 읽고 싶을 때. 상대적으로 느릴 수 있음 |
| PaddleOCR v5 (속도 우선) | 빠른 처리가 중요할 때. 고속 모델이 설치되어 있으면 우선하며, 복잡한 글꼴에서는 오인식이 늘 수 있음 |
| PaddleOCR v5 검출 + v6 인식 (균형형) | 검출과 인식을 다른 모델로 조합해 속도·정확도의 균형을 노릴 때 |

특히 PaddleOCR의 `default`는 호환성을 위한 저장 ID이고, 화면의 **v5 (속도 우선)**이라는 이름과 별개다. 기존 v5 고속 모델이 있으면 우선하며, 없으면 기존 v5 경로를 사용한다. 이 선택에 따라 실제 속도는 달라질 수 있다. 모델의 내부 ID와 기존 게임 프로필 설정은 바꾸지 않는다.

## 로컬 AI 번역

번역 서비스에서 **로컬 AI 번역**을 선택한 뒤 **로컬 AI 모델**에서 모델을 고른다. 기본값은 **표준 — Hy-MT2 7B (약 4.6GB)**다. **경량 — Hy-MT2 1.8B (약 1.1GB)**는 메모리 사용량과 대기 시간을 줄이지만 표준보다 품질이 낮으며 부정문·명령·문맥을 잘못 번역할 수 있다. 선택은 게임 프로필별로 저장한다. API 키·서버 주소·GPU 설정은 필요하지 않다. 모델이 없으면 **번역 시작** 때 선택 모델의 이름·용량·설명을 포함한 설치 확인을 표시하며, **예**를 누르면 다운로드·검증·엔진 준비 후 번역 시작을 자동으로 이어간다. 설치 확인과 진행 창은 항상 위에 표시한다. 취소 후 다시 시작하면 가능한 부분을 이어받는다.

**번역 서비스 → 로컬 AI 모델 → 모델 관리**의 **설치** 버튼으로 선택한 모델을 미리 준비할 수도 있다. 설치를 마치면 버튼이 **삭제**로 바뀐다. 삭제는 확인 후 선택한 모델과 해당 다운로드 데이터만 제거하며 다른 모델은 보존한다. 설치는 모든 프로필이 공유하지만 모델 선택은 각 프로필에 저장된다. 모델을 바꾸면 진행 중인 로컬 번역을 중지하고 이전 Worker를 정리한다. **설정 저장 → 시작**을 누르면 선택한 모델을 사용한다. 이미 설치된 정상 모델은 다운로드 창 없이 재사용한다. 기존 7B는 `%LOCALAPPDATA%/KoTrans2/Models/HyMT2`, 경량은 그 아래 `1.8B`에 저장하므로 앱 실행 파일 교체 때 유지된다. 설치 뒤 번역에는 인터넷이 필요하지 않다.

GPU 가속을 먼저 시도하며 준비할 수 없으면 CPU로 전환한다. CPU 준비에는 표준은 가용 RAM 6GiB, 경량은 3GiB 이상이 필요하다. CPU 모드는 느릴 수 있고 실제 지연과 메모리는 게임·PC에 따라 다르다. 메모리가 부족해도 다른 모델을 자동 선택·다운로드하지 않는다. 짧은 게임 대사 영역을 지정하고, 긴 입력이나 출력 한도 안내가 나오면 영역을 줄인다. 로컬 제공자는 문장 해설을 지원하지 않는다.

표준·경량 모델 모두 최근 원문을 맥락으로 참고하되 현재 원문만 번역하도록 요청한다. **캐릭터 사전**을 사용하면 현재 원문에 실제 등장한 이름의 표기 지침을 전달한다. 로컬 모델에는 인물 설명을 보내지 않으며, 모델이 표기를 항상 지킨다고 보장하지는 않는다.

OpenAI·Gemini·Ollama Chat·로컬 표준/경량 모델은 같은 성·이름 보정 처리를 사용한다. 전체 이름이 `佐藤美咲 → 사토 미사키`로 등록되어 있으면 원문에 성 `佐藤`만 나올 때는 `사토`, 이름 `美咲`만 나오면 `미사키`를 지침으로 전달한다. 한국어 전체 이름은 성과 이름을 공백으로 구분한다. 서로 다른 인물의 표기가 충돌하거나 구분 근거가 불충분하면 자동으로 추측하지 않는다. 별명이나 특수한 이름은 짧은 표기를 별도 항목으로 등록하면 해당 명시적 표기가 우선한다. 캐릭터 사전 미지원 방식인 DeepL·Ollama TranslateGemma에는 적용하지 않는다.

## 번역 시작/중지와 인식 방식

**번역 시작**을 누르면 기본 입력 설정을 확인한 뒤 오버레이에 **“번역을 시작하기 위한 준비를 하고 있습니다. 잠시만 기다려 주세요.”**를 먼저 표시한다. 원문 전용 모드에서는 “원문 인식” 준비로 안내한다. 모델 확인·엔진 준비가 끝나면 자동 인식 또는 기존 입력 트리거 안내로 이어진다. 준비 중 자막창을 닫으면 시작을 취소한다. 설치 동의를 거절하거나 준비에 실패하면 준비 안내를 끝내고 시작 안내로 돌아가며, 실패 원인은 별도로 표시한다.

**프로필 → 기본 정보 → 원문 읽기**에서 **일본어 원문에 한자 읽기(후리가나) 표시**를 켜면 오버레이의 확정 일본어 원문 위에 읽기를 표시한다. 기본 OFF이며 게임 프로필별로 저장한다. 일본어 선택에서만 보이고 영어로 바꾸어도 체크 값은 보존한다. 크기는 원문 글자의 **60%**를 기본으로 하며 촘촘한 읽기끼리 겹치면 해당 읽기만 작게 맞춘다. 원문 글자 크기·색 변경도 함께 반영된다. 읽기는 로컬 사전을 사용하므로 추가 AI 호출이 없으며, 알 수 없는 인명·고유명사 등은 생략할 수 있다. 사전 호버/클릭은 기존 원문 단어로 동작하고, 번역·클립보드로 보내는 원문에는 후리가나를 넣지 않는다.

**번역 시작**(기본 Shift+F1)은 선택한 인식 방식을 실행한다. **번역 중지**는 화면/클립보드 감시와 게임 입력 트리거를 해제하고 진행 중 OCR·번역을 취소한다. 중지 중에 Enter·Space·클릭 같은 트리거를 눌러도 번역을 재개하지 않는다. 게임의 입력은 그대로 동작한다. Shift+F1은 별도의 시작/중지 단축키다.

알림 영역 아이콘 우클릭 메뉴의 **열기** 아래에서도 같은 **번역 시작/중지**를 사용할 수 있다. 한국어 번역 표시가 꺼져 있으면 메인 버튼과 같이 **원문 인식 시작/중지**로 표시한다. 시작 성공 시 메인 창을 숨기고, 시작하지 못하면 메인 창에서 이유를 확인할 수 있다.

**프로필 설정 → 고급 설정 → 클립보드**의 **OCR 결과 클립보드로 복사**는 기본 OFF이며 프로필별로 저장한다. ON이면 안정화가 끝난 화면 OCR 원문을 번역 요청 직전에 복사한다. 한국어 번역 표시가 꺼져 있어도 확정 원문은 복사할 수 있다. 아직 변하는 후보 원문이나 한국어 번역은 복사하지 않는다. 클립보드 입력 모드에서는 이 옵션을 비활성화하고 기존 체크 값은 보존한다. 클립보드를 사용할 수 없으면 복사 실패를 안내하고 인식·번역은 계속한다.

**프로필 → 인식 방식 · 트리거**의 라디오 버튼으로 두 방식을 선택한다. 기본은 **화면 자동 인식 사용**이며 프로그램 실행만으로 번역을 시작하지는 않는다. 저장된 선택과 입력 키 값은 보존한다.

- ON: 화면이 바뀌면 OCR을 실행한다. 키보드·마우스·게임패드 트리거는 작동하지 않으며 관련 설정은 흐리게 비활성화된다.
- 입력 트리거 사용: 입력이 들어오면 설정된 초기 대기 뒤 화면 확인을 시작한다. 이후 화면·문장 안정화, OCR, 번역은 자동 인식과 같은 경로를 사용한다. 결과가 확정되면 다음 입력까지 캡처하지 않는다. 이전 대사가 잠시 남거나 연출이 있어도 새 문장을 기다리며, 확인은 최대 12초로 제한한다.

입력 트리거 후 OCR 대기의 기본값은 **0ms**다. 필요하면 0–5000ms로 조절할 수 있고, 기존에 저장한 값은 유지한다. 0ms에서도 화면·문장 안정화 확인은 그대로 수행한다.

게임패드는 **+ 버튼 추가**를 누른 뒤 원하는 버튼을 직접 누르면 등록된다. 여러 버튼을 하나씩 추가할 수 있으며 각 항목의 **×**로 삭제한다. 기본값은 **A·B**다. XInput 패드의 A/B/X/Y, LB/RB, LT/RT, 방향 버튼, 스틱 누르기, 시작/뒤로 버튼을 지원한다. 스틱 방향 이동은 등록하지 않는다. 이미 누르고 있던 버튼은 한 번 놓았다가 눌러야 하며, Esc·입력 취소 또는 다른 화면으로 이동하면 등록 대기를 취소한다. 게임에 전달되는 입력은 차단하지 않는다.
- 예전 설정에서 두 방식 모두 OFF이거나 입력 모드에서 선택한 입력이 없음: 인식 방식과 입력을 선택하도록 안내한다.
- 클립보드 모드: 클립보드 변경만 감시한다. 화면/게임 트리거 설정은 보존한 채 비활성화된다.

변경한 뒤 **설정 저장**을 누르고 다시 시작한다. 설정 저장 또는 메인 화면으로 복귀하면서 인식 설정을 적용하면 진행 중 번역은 중지한다. 메인 시작 버튼 아래에서 선택한 인식 방식을 확인할 수 있다. 원문 전용일 때 버튼은 **원문 인식 시작/중지**로 표시한다.

## 인식 영역 편집

프로필의 **캡처 · OCR**에서 **캡처 대상**과 게임 캡처 영역을 먼저 지정한 뒤, 필요한 경우 OCR 모델을 콤보박스에서 선택한다. 선택한 OCR 모델의 특징은 콤보박스 아래에 표시한다. 정상 상태의 파일 준비 안내는 생략하고, 모델 파일이 없거나 잘못된 구성이면 오류를 표시한다. 실제 해시·모델 형식 검사는 첫 인식 때 수행한다. 모델 및 GPU 가속 설정을 변경하면 진행 중인 번역은 중지된다. 다시 시작하면 적용된다.  **화면 영역**과 **클립보드**에서는 대상 창 선택 버튼을 사용하지 않는다. 저장한 게임 창 정보는 남아 있어 **게임 창**으로 돌아오면 다시 연결된다. 클립보드는 텍스트 후킹 프로그램 등이 복사한 게임 텍스트를 읽으며 영역을 지정할 필요가 없다. 캡처 영역 옆의 고정된 작은 배치도는 모니터/게임 창 안의 인식 위치를 파란색으로 보여준다. 게임 연결이 끊기거나 영역/화면 정보가 없으면 같은 자리에 **미리보기 없음**을 표시하며, 저장된 좌표와 영역은 유지한다. 캡처 대상과 영역 설정 사이를 구분선으로 나누고, **캡처 영역** 제목 바로 아래에 화면/게임 창 기준, 위치(X/Y), 크기(가로×세로 px)를 순서대로 표시한다. 자세한 좌표 설명은 마우스 툴팁에서 확인한다. 실제 화면 이미지를 저장하지 않는다.

**영역 지정**을 누르면 저장된 사각형을 다시 편집한다. 아직 지정하지 않았다면 빈 곳에서 드래그해 새 사각형을 만든다. 마우스를 놓아도 확정되지 않는다.

- 사각형 내부를 드래그하면 이동한다.
- 네 테두리는 좌우/상하 크기 조절 커서, 네 모서리는 대각선 커서로 바뀐다. 드래그해서 늘이거나 줄일 수 있다. 작은 네모 조절 표시는 띄우지 않는다.
- **확정**을 눌러야 현재 크기와 위치가 저장된다. **취소 (Esc)**로 닫으면 기존 설정을 유지한다.
- **새로 그리기**는 편집 중 사각형만 지운다. 빈 곳에서 새로 드래그한 뒤 확정한다.

영역은 한 모니터 안에 배치하며 최소 4×4px다. 다른 모니터에서도 새로 그릴 수 있다. 특정 윈도우 모드는 게임 창 내부 상대 좌표로 저장한다. 게임 창이 이동하면 기존 영역도 그 위치를 따라 편집한다. 게임 창이 작아졌거나 실행 중이 아니어도 마지막 영역을 열어 수정할 수 있으며, **확정 시에는 게임 창이 사용 가능하고 영역이 그 안에 있어야 한다**. 처음 실행의 기본 좌표는 미지정으로 표시하며 옛 설정 파일에 있던 좌표는 보존한다.

## 모델 목록과 자막 표시 선택

오버레이 왼쪽 위의 옅은 녹색 **서비스명 버튼(Gemini/OpenAI 등)**을 누르면 설정창 단축키(기본 F1)와 동일하게 메인창을 앞으로 표시한다. **게임에 클릭 전달**을 켜 놓아도 사용할 수 있다. 버튼을 눌러도 번역을 시작하거나 중단하지 않으며, 원문만 보는 경우에는 `원문만 표시` 버튼으로 표시된다.

Gemini/OpenAI의 모델 ID 옆 **모델 목록**을 누르면 등록한 API 키로 공식 목록을 조회한다. 검색한 뒤 모델을 더블클릭하거나 **모델 ID 적용**을 눌러 입력한다. 선택한 ID는 아래 읽기 전용 입력란에서 마우스로 선택해 복사할 수도 있다. **설정 저장**으로 확정하며 목록을 열기만 해서는 모델이 바뀌지 않는다. 비용은 목록 창의 **공식 요금표**에서 확인한다. 목록에 있어도 번역 API 호환성은 모델마다 다르다.

**프로필 설정 → 자막창**에서 **원문 표시**와 **한국어 번역 표시**를 각각 선택한다. 둘 중 하나 이상은 켜야 한다. 한국어 번역을 끄면 **원문 인식 시작**으로 원문만 보며 번역 API를 호출하지 않는다. 키와 번역 모델 ID를 지정할 필요도 없다. 두 옵션은 프로필마다 저장되며 기존 프로필의 번역은 기본 켜짐이다. 실행 중 표시 모드를 바꾸면 필요한 경우 처리 세션을 다시 준비하고 기존 인식 방식으로 이어간다.

오버레이의 번역 서비스 버튼 오른쪽에는 차분한 붉은색 **자막 표시 버튼**이 있다. 현재 상태를 표시하며 누를 때마다 **원문+번역 → 원문 → 번역 → 원문+번역**으로 바뀐다. 설정의 두 체크박스와 양방향으로 동기화되며 즉시 저장한다. 같은 원문의 완료된 번역은 다시 요청하지 않고 표시한다. 새 원문에는 이전 문장의 번역을 재사용하지 않는다. 버튼으로 전환할 때 필요한 내용이 없으면 보관된 원문을 번역하거나 OCR부터 수행하고, 처리 중에는 안내를 표시한다. 원문 전용에서는 번역을 요청하지 않는다. 키·모델·캡처 대상이 준비되지 않은 경우에는 실패 이유를 표시한다.

**번역 자막창** 제목 옆 **자막창 표시/자막창 감춤**은 창만 열고 숨긴다. 표시 버튼으로 번역을 시작하지 않으며 감춤 버튼으로 진행 중 감시를 중지하지 않는다. 자막창 자체의 **×**는 기존처럼 OCR·자동 번역을 중지한다.

색상 선택 목록에는 **흰색·노란색·하늘색** 같은 이름과 색상 견본을 표시한다. 임의로 선택한 색은 **사용자 지정 색상**과 견본으로 표시하며 기존 저장 색상을 유지한다. 아래 **자막 미리보기**는 원문/번역의 글자 크기·색상·표시 여부와 불투명도를 즉시 반영한다. 샘플 문구만 사용하며 게임 화면을 캡처하지 않는다.

입력 트리거 방식으로 시작하면 자막 크기의 **설정한 입력 트리거를 누르면 번역을 시작합니다** 안내가 첫 입력까지 한 번 표시된다. 이후 입력마다 반복하지 않는다. 중지 상태에서는 **자막창의 ‘시작’ 버튼을 누르면 번역을 시작합니다**를 표시하고, 다시 시작하면 없어진다. 원문만 표시하는 프로필은 번역 대신 **원문 인식**으로 안내한다. 이 안내는 실제 OCR 원문이나 번역 결과로 저장·전송하지 않는다.

## Gemini 번역 표시

일반 번역은 생성된 부분부터 표시하고, 완료된 응답만 정상 문맥에 저장한다. 수신 중에는 아직 확정되지 않은 번역임을 안내한다. 스트림이 중단되면 오류를 표시하며 자동으로 다시 전송하지 않는다. 문장 해설의 JSON 처리는 별도로 유지한다.

번역 서비스의 기본 설정 항목은 **모델 ID**, **응답 대기 시간 (초)**처럼 간결하게 표시한다. Gemini·OpenAI는 문장 해설 지원 여부만 짧게 안내하고, DeepL은 번역 전용이며 문장 해설·캐릭터 사전을 지원하지 않는다고 표시한다. API 키는 모든 게임 프로필이 공유하며, 인증 여부와 기본 프로필의 관리 버튼을 통해 확인할 수 있다. 로컬 AI는 모델별 설명과 설치 상태를 **모델 관리**에 표시하고 인터넷 연결 없이 번역할 수 있음을 안내한다.

## Ollama 로컬 모델

Ollama가 실행 중이고 해당 모델이 설치되어 있어야 한다. 서버 주소의 기본값은 `http://localhost:11434`다. 모델 ID와 별도로 **요청 방식**을 선택한다. 화면에는 Chat(일반 대화형 모델)과 TranslateGemma(번역 전용 모델)가 표시되며, 선택한 방식의 특징이 바로 아래에 안내된다. 모델 이름이나 별칭만 보고 형식을 추측하지 않는다.

- 일반 대화형 모델: **Chat**. 문장 해설에는 JSON 출력을 지원하는 모델이 필요하다.
- `translategemma:12b`: **TranslateGemma**. 프로필의 영어/일본어 원문을 한국어로 번역한다. [공식 입력 형식](https://ollama.com/library/translategemma)에 맞게 원문만 한 요청으로 보내며 대화 이력·캐릭터 사전 지시·학습 JSON은 지원하지 않는다. 학습이 필요하면 그 기능을 지원하는 대화형 모델로 직접 변경한다.

요청 방식·응답 대기 시간·모델 유지 시간은 **Ollama 모델 ID별**로 저장한다. 기본 로컬 제한 시간은 120초이며 5–300초로 바꿀 수 있다. 모델 ID 입력 후 다른 항목으로 이동하면 해당 모델에 저장된 값을 불러온다. **적용** 전 변경은 기존 설정에 저장되지 않는다.

첫 실행에는 모델 로딩과 첫 입력 처리가 오래 걸릴 수 있다. **모델 유지 시간** 기본값은 10분이며, 재로딩을 줄이는 대신 그동안 GPU/RAM을 사용한다. 0분은 요청 뒤 바로 해제하며, 게임 메모리가 부족하면 유지 시간을 줄인다. 앱 시작 시 모델을 자동 로딩하거나 다운로드하지 않는다. 모델 크기·GPU/메모리·입력 길이에 따라 최초 번역은 3초를 넘을 수 있다.

연결 실패는 Ollama 실행·주소·포트를 확인하고, 모델/형식 오류는 설치된 ID와 선택한 요청 방식을 확인한다. 시간 초과는 대기 단계와 제한 시간을 함께 안내한다. 서버가 원인을 반환하지 않았다면 GPU/메모리 부족 등을 확정하지 않으며, 로딩 상태와 자원을 확인한 후 필요하면 수동 재시도한다. 요청 원문이나 HTTP 응답을 로그로 공개하지 않는다. Ollama 내부 실행기 연결 종료는 서버 내부 통신 오류로 따로 안내한다. 정상 취소도 Ollama 서버 로그에 500으로 남을 수 있어 로그 숫자만으로 앱 실패 횟수를 판단하지 않는다. 반복되는 실제 연결 오류는 진행 중 작업을 마친 뒤 Ollama의 정상 재시작을 검토한다.

## 문장·어휘 학습

**Shift+F2**를 누르면 현재 입력을 학습한다. 화면/창 입력은 현재 화면과 같은 최근 OCR을 재사용하거나 새 OCR을 수행한다. 클립보드는 사용자가 요청한 순간의 텍스트를 읽는다. 번역을 먼저 켤 필요는 없다.

문장 해설창은 **읽기 전용 다크 테마 뷰어**다. 원문을 맨 위에 보여주고, 전체 한국어 해석을 강조한 다음 문장 구조·뉘앙스와 어휘·예문·사용 팁을 순서대로 표시한다. 자동 번역만 켜 두었다고 유료 학습 요청이 실행되지는 않는다.

문장 해설을 가져오는 동안은 **22pt 안내와 회전하는 모래시계**를 보여 주며, 성공·취소·오류·창 숨김 시 회전을 멈춘다. 원문(21pt), 전체 해석(23pt), 문법·어휘·예문 글씨도 전체적으로 키워 읽기 편하도록 조정했다.

다음 문장을 해설하려면 게임에서 학습 단축키를 사용한다. 프로필 전환이나 X로 해설창을 숨기면 진행 중인 분석이 취소된다. 최근 같은 분석은 메모리에서 재사용한다. 결과는 하나의 스크롤 영역으로 읽으며 기본 **Shift+PageUp / Shift+PageDown**은 학습창에 포커스가 없어도 위/아래로 스크롤한다. 숨긴 창은 열지 않는다. 키는 공통 설정에서 변경 가능하며, 다른 프로그램과 등록이 충돌하면 안내한다. 기존 옛 학습 기본키는 충돌이 없을 때 새 키로 이전하고 별도 지정한 키는 보존한다. **기본 프로필 → 공통 설정 → 문장 해설창 항상 위**에서 기존 항상 위 옵션을 바꿀 수 있다.

문장 해설창을 **X로 닫을 때 위치·크기·모니터를 현재 게임 프로필에 저장**한다. 다음에 표시할 때 같은 모니터의 배치로 복원한다. 모니터 배치나 배율이 바뀌면 작업 영역 안으로 조정하며, 저장한 모니터가 연결되지 않았으면 현재 모니터에 임시 표시한다. 그 상태에서 그냥 닫으면 원래 배치를 보존하고, 직접 이동하거나 크기를 바꾼 뒤 닫으면 새 배치를 저장한다. 예전 공통 위치 설정도 새 프로필별 배치가 없을 때 계속 사용한다.

번역 제공자·모델·프로필 또는 원문 입력 설정을 변경하면 이전 해설을 비우고 **그 이유와 다시 요청하는 단축키**를 해설창에 표시한다. 제공자·모델 변경 안내에는 현재 서비스와 모델 ID도 표시한다. 설정 변경으로 자동 재분석하지 않으며, 게임에서 문장 학습 단축키를 눌러 다시 요청한다.

## 영어 발음 표기와 일본어 읽기

영어 단어의 IPA는 어휘 옆에 텍스트로 표시한다. 일본어 원문은 **한자뿐 아니라 히라가나·문장부호까지 전체 글자를 동일하게 크게** 표시한다. 로컬 사전으로 확인된 한자 포함 단어에는 바로 위에 **히라가나 루비(후리가나)**를 붙이며, 고유명사·동형어의 읽기는 임의로 채우지 않는다. 어휘 표제어도 적절한 읽기가 있을 때 루비를 사용한다.

## 종료와 문제 해결

메인 창의 X는 알림 영역으로 숨긴다. 완전히 종료하려면 **알림 영역 KO Trans 2 아이콘 우클릭 → 종료**를 선택한다. 설정 저장 실패 후 종료를 취소했다면 번역/학습은 중지 상태라는 안내가 표시되며 **번역 시작 또는 학습 단축키**로 다시 사용할 수 있다. 캡처와 모델 정리가 끝날 때까지 잠시 기다린다.

- 모델 누락·SHA 오류: 배포 원본의 models 폴더를 복원한다. 출처 불명 모델을 이름만 바꿔 넣지 않는다.
- 글자가 잘리거나 틀림: 언어·세로쓰기·읽기 모드와 영역을 확인한다. 작은 일본어/후리가나는 확대가 필요하므로 속도만을 위해 무조건 줄이지 않는다.
- 게임 창 캡처 실패: 최소화·보호 화면·독점 전체화면·다른 창의 가림을 확인한다. 이 앱은 보이는 화면을 읽는다.
- 학습창/번역창이 캡처를 가림: Windows의 캡처 제외가 지원되지 않는 경우 창을 영역 밖으로 옮기거나 숨긴다.
- API 오류: 키·선택 모델·주소·네트워크·사용 한도를 확인한 뒤 직접 재시도한다. 키나 대화 원문을 공개 로그에 붙이지 않는다.

OCR 정확도와 캡처 동작은 게임과 Windows 구성에 따라 달라질 수 있다.

## 게임별 프로필 복원

기본 프로필도 게임 번역에 사용할 수 있다. **새로 만들기**는 기본 프로필의 언어·OCR·번역·자막 옵션을 복사한다. 새 게임의 대상 창과 대사 영역은 직접 지정한다. 특정 윈도우에서 부분 영역을 지정하기 전에는 선택한 창 전체를 사용한다. 클립보드 모드는 영역 지정 없이 사용할 수 있다. 기존 프로필에는 저장해 둔 영역이 유지된다.

프로필 이름을 입력한 뒤 **설정 저장** 또는 **이름 변경**을 누르면 같은 방식으로 적용·저장한다. 다른 프로필로 전환하거나 정상 종료할 때도 편집한 이름을 보존한다. 빈 이름은 저장하지 않고 수정을 안내한다.

**캡처 대상: 게임 창 → 대상 창 선택 → 선택**으로 대상을 즉시 저장한다. 게임 창이 최소화돼 있어도 대상 선택은 저장되며, 캡처는 게임 창을 복원한 뒤 가능하다. 게임 창이 자동으로 연결되지 않으면 **대상 게임**과 함께 **연결 대기 · 게임을 실행하세요. 실행 중이라면 대상 창을 다시 선택하세요.**라고 안내한다. 후보가 여러 개면 직접 선택해야 하며 저장 정보가 사라진 것은 아니다.

마지막 선택한 프로필을 다음 실행에서 복원한다. 선택만으로 번역이나 유료 AI를 시작하지 않으며, **번역 시작**을 직접 눌러야 한다. 게임별 입력 후 OCR 대기(0–5000ms)와 인식 방식은 **프로필 → 인식 방식 · 트리거**에서 지정한다. **입력 트리거 사용**으로 설정하면 번역을 시작한 뒤 지정한 게임 입력으로 인식을 시작한다. 캐릭터 사전을 꺼도 파일 경로는 보존한다.

최초 기본값은 마우스 트리거 **Left**, 키보드 **Enter·Space**, 캐릭터 사전 사용 **꺼짐**이다. 이미 저장된 값은 바꾸지 않는다. 새 게임 프로필은 현재 기본 프로필의 설정을 복사한다.

**설정 저장**을 누르면 저장 중 중복 클릭을 막고, 파일에 저장된 뒤에만 체크와 **저장 완료**를 잠깐 표시한다. 프로필 생성·이름 변경·전환·삭제도 화면 안의 작은 알림으로 완료를 알려준다. 오류 토스트는 3초 뒤 사라지며, 세부 오류는 상태바에서 계속 확인할 수 있다. 토스트가 사라져도 실패한 작업이 성공한 것은 아니므로 입력값이나 접근 권한을 확인해 다시 시도한다. 저장 중 추가 편집이 있으면 그 변경은 별도 저장이 필요하다고 안내한다.

OCR 모델 선택의 **저장 필요**는 메모리에 적용됐다는 뜻이다. **설정 저장** 또는 기존 화면 이동 저장이 성공해야 파일에 반영된다. 내부 자동 저장에는 매번 완료 알림을 띄우지 않는다.

창 폭이 좁으면 프로필 선택을 두 번째 줄로 옮기고 설정 메뉴를 위쪽에 가로로 배치한다. 장식 이미지는 숨겨 조작 공간을 확보하며, 긴 설정은 내부 스크롤로 읽는다. 창 크기는 현재 모니터의 배율과 작업 영역 안으로 제한한다.

자막 위치·크기·모니터는 게임별로 저장한다. 모니터가 빠지면 현재 화면에 임시 표시하며 저장했던 위치를 지우지 않는다. 원래 모니터가 돌아오면 복원한다. 임시 위치를 새 기본 위치로 삼으려면 자막을 직접 이동/크기 조정한다. 사용자 지정 RGB 색상도 유지한다.

창 제목이 바뀌거나 같은 에뮬레이터에서 게임을 바꿨다면 직접 확인하고 대상을 다시 선택한다. 창 식별은 실행 창의 일치 확인이며, 제목까지 같은 에뮬레이터 내부 ROM/디스크의 동일성을 확인하는 기능은 아니다. 모니터 인터페이스 ID가 드라이버/연결 장치 변경으로 달라지면 안전한 임시 위치를 사용한다. 구버전에 모니터 ID가 없는 배치는 좌표 기준으로 복원하며 한 번 직접 이동/크기 조정하면 새 식별 정보를 저장한다.

자막창을 다시 여는 것은 번역 시작과 별개다. 실제 × 닫기 뒤 다시 열면 시작 안내를 표시하며, **번역 시작**으로 재개한다. 프로필 교체를 위한 내부 창 정리는 사용자 닫기로 표시하지 않으며, 같은 프로필을 다시 선택하는 것만으로 실행 중 번역을 중지하지 않는다.

공통 설정은 **문장 해설창**, **API 제공자 인증정보**, **단축키** 세 패널로 나뉜다. 기본 프로필의 이름은 프로필 선택 목록과 선택된 표시에서 차분한 붉은 와인색으로 구분한다. 공식 모델 목록 창은 **검색어 입력:**으로 필터링하고 **선택된 모델:**에서 ID를 복사하거나 적용한다.

프로필에 게임 실행 파일 경로가 저장되어 있으면 메인 시작 버튼 왼쪽에 **게임 실행**이 표시된다. 캡처 모드와 관계없이 실행을 요청하며, 번역은 시작 버튼으로 별도로 켠다. 경로가 없으면 버튼을 표시하지 않는다. Steam·런처·에뮬레이터 등에 별도 실행 주소나 인자가 필요한 경우에는 게임을 직접 실행한다.

## ZIP 업데이트와 버전별 설정 백업

새 ZIP은 완전히 종료한 다음 별도 폴더에 풀고 KoTrans2.exe를 직접 실행한다. 새 버전이 정상 동작한 뒤 이전 프로그램 폴더를 지운다. %LOCALAPPDATA%/KoTrans2의 프로필·DPAPI 키·Models는 그대로 두며 프로그램 폴더에서 사용자 사전/음성을 직접 관리했다면 삭제 전에 별도로 보관하고 경로를 다시 지정한다. 다른 PC/Windows 계정의 API 키는 재등록이 필요할 수 있다.

새 릴리즈 첫 실행에서 기존 settings.json을 바꾸기 전에 Backups/settings-before-...json으로 원본 바이트를 자동 보관한다. 같은 릴리즈는 중복 생성하지 않고 최근 관리 백업 5개를 유지한다. 백업에 실패하거나 설정을 읽을 수 없으면 원본 보호를 위해 저장을 중단한다. 정상 업데이트에는 추가 확인창이 없다.

복구할 때는 앱을 완전히 종료하고 현재 settings.json을 별도로 보관한 뒤, 복구 대상 버전 실행 전의 Backups 파일을 복사해 settings.json으로 이름을 바꾼다. 새 설정을 구버전 앱이 항상 읽을 수 있는 것은 아니다. update-state.json/Backups 자체가 손상되었거나 충돌하면 둘을 별도 이름으로 보관한 후 복구한 settings.json으로 재실행한다. 암호화된 키와 Models 폴더는 변경하지 않는다. 상세한 개발/복구 절차는 저장소 docs/portable-release.md를 참고한다.
