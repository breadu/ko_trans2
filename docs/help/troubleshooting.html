    KO Trans 2 · 사용자 도움말

    문제 해결과 자주 묻는 질문

    화면에 표시된 상태와 아래 증상을 대조해 보세요.

    게임 창이 목록에 나타나지 않아요

    가능한 원인
    게임이 아직 열리지 않았거나 창이 숨겨져 있을 수 있습니다.
    확인 방법
    작업 표시줄에서 게임 창을 복원해 실제로 보이는지 확인하세요.
    해결 절차
    대상 창 선택을 다시 열거나 대상 창 직접 클릭을 사용하세요. 연결이 어려우면 게임을 창 모드로 전환하고 화면 영역을 시도하세요.

    게임 창을 선택했는데 인식되지 않아요

    가능한 원인
    게임이 전면에 없거나 대사 영역이 가려져 있을 수 있습니다.
    확인 방법
    게임을 전면에 놓고 대사가 보이는지, 캡처 미리보기가 올바른지 확인하세요.
    해결 절차
    가리는 창을 옮기거나 최소화하고 영역 지정을 다시 하세요. 보호 화면과 독점 전체화면은 보이는 창으로 전환할 수 있는지 게임 설정에서 확인하세요.

    번역 시작을 눌렀는데 멈춘 것 같아요

    가능한 원인
    게임 창 미지정, 로컬 AI 준비 중 또는 입력 트리거 대기일 수 있습니다.
    확인 방법
    메인 상태 표시와 자막의 준비·대기 안내를 확인하세요.
    해결 절차
    캡처 · OCR에서 대상과 영역을 확인합니다. 모델을 준비하는 중이면 기다리고, 입력 트리거를 선택했다면 지정한 게임 입력을 누르세요.

    일본어가 잘리거나 글자가 틀려요

    가능한 원인
    언어·읽기 방향이 다르거나 대사 상자가 영역 밖에 걸쳐 있을 수 있습니다.
    확인 방법
    기본 정보의 일본어·읽기 모드와 캡처 미리보기를 확인하세요.
    해결 절차
    다음 줄까지 포함하도록 영역을 넓히고 장식과 메뉴 글자는 제외합니다. 가로·세로 방향을 맞추고 다른 OCR 모델을 같은 장면에서 비교하세요.

    한국어 번역이 나오지 않아요

    가능한 원인
    원문 전용으로 시작했거나 번역 서비스가 응답을 기다릴 수 있습니다.
    확인 방법
    시작 버튼이 원문 인식 시작인지, 원문은 자막에 들어오는지 확인하세요.
    해결 절차
    자막창 → 한국어 번역 표시를 켜고 저장한 뒤 번역을 다시 시작하세요. 원문만 정상이라면 제공자와 모델 또는 인증 상태를 확인하세요.

    OCR이 느리거나 같은 장면을 자꾸 읽어요

    가능한 원인
    영역이 넓거나 배경 변화가 많고, OCR 모델의 CPU 비용이 클 수 있습니다.
    확인 방법
    OCR 상태가 CPU인지 GPU인지, 영역에 애니메이션이 들어가는지 확인하세요.
    해결 절차
    대사 영역만 지정하고 v5와 v6을 비교해 보세요. 지원 구성은 OCR GPU 가속 사용 (DirectML)을 시험할 수 있습니다. 클릭으로 대사를 넘기는 게임은 입력 트리거가 도움이 될 수 있습니다.

    로컬 AI 모델 설치 또는 준비에 실패해요

    가능한 원인
    연결 중단, 저장 공간 부족, 모델 검증 오류 또는 실행 메모리 부족일 수 있습니다.
    확인 방법
    준비 창의 오류 문구와 여유 공간·메모리를 확인하세요.
    해결 절차
    번역 서비스 → 로컬 AI 모델 → 모델 관리에서 설치 상태를 확인하고 다시 시도합니다. 메모리가 부족하면 다른 작업을 닫거나 경량 모델을 선택하세요. OCR 모델 누락 안내라면 배포본의 models 폴더를 복원하세요.

    Ollama에 연결되지 않거나 답이 늦어요

    가능한 원인
    서버가 실행되지 않았거나 주소·모델 ID·요청 방식이 다를 수 있습니다.
    확인 방법
    연결 확인으로 서버 상태를 보고 모델 목록에 대상 모델이 있는지 확인하세요.
    해결 절차
    서버를 켜고 정확한 주소와 모델을 선택합니다. 모델에 맞는 요청 방식을 저장하세요. 첫 모델 로딩이 길다면 응답 대기 시간과 PC 자원을 확인합니다.

    API 인증 오류가 나요

    가능한 원인
    키가 등록되지 않았거나 만료됐거나, 선택한 모델의 이용 권한·한도가 없을 수 있습니다.
    확인 방법
    기본 프로필의 공통 설정 → API 제공자 인증정보에서 해당 제공자의 등록 상태를 확인하세요.
    해결 절차
    정상 키를 입력하고 키 등록/변경을 누릅니다. 제공자의 모델 사용 권한과 사용량 한도를 확인한 뒤 다시 시작하세요.

    게임을 옮겼더니 캡처 위치가 달라요

    가능한 원인
    화면 영역 모드는 모니터의 고정 좌표를 사용합니다. 게임 해상도나 확대 상태가 바뀌어도 위치가 달라질 수 있습니다.
    확인 방법
    캡처 · OCR에서 캡처 대상과 영역 미리보기를 확인하세요.
    해결 절차
    게임을 자주 옮기면 게임 창으로 연결해 영역을 다시 정하세요. Magpie 사용 시 고급 설정의 원본 화면 옵션을 확인하세요.

    자막창이 보이지 않아요

    가능한 원인
    자막창을 닫았거나 다른 모니터·게임 창 배치로 옮겨졌을 수 있습니다.
    확인 방법
    현재 프로필과 프로필 설정 → 자막창의 표시 옵션을 확인하세요.
    해결 절차
    자막창 열기를 누르고 보이는 위치로 옮깁니다. 자동 인식이 중지된 경우에는 번역도 다시 시작합니다.

    단축키가 동작하지 않아요

    가능한 원인
    다른 앱이나 KO Trans 2의 다른 인스턴스에서 같은 키를 사용 중일 수 있습니다.
    확인 방법
    메인 상태 표시의 단축키 등록 실패 메시지를 확인하세요.
    해결 절차
    기본 프로필 → 공통 설정 → 단축키에서 비어 있는 조합을 지정하고 저장하세요. F1이 안 되면 알림 영역 아이콘의 열기를 사용합니다.

    창을 닫았는데 앱이 계속 실행돼요

    가능한 원인
    메인 창의 ×는 앱을 알림 영역에 숨깁니다.
    확인 방법
    작업 표시줄의 숨겨진 알림 아이콘에서 KO Trans 2를 찾으세요.
    해결 절차
    아이콘을 우클릭해 종료를 누르고 앱이 정리될 때까지 기다리세요.

    새 ZIP 버전으로 어떻게 업데이트하나요?

    가능한 원인
    ZIP은 별도 폴더에 푸는 방식이며 게임 프로필과 인증 정보는 사용자 계정에 저장됩니다.
    확인 방법
    기존 KO Trans 2가 실행 중인지, 새 ZIP을 압축 해제할 저장 공간이 충분한지 확인하세요.
    해결 절차
    앱을 완전히 종료하고 새 ZIP을 별도 폴더에 모두 푼 뒤 새 KoTrans2.exe를 엽니다. 프로필과 자막이 정상인지 확인한 뒤 이전 프로그램 폴더를 정리하세요. 문제가 생기면 앱을 모두 종료하고 기존 설치 폴더와 사용자 설정 백업을 보존하세요.
