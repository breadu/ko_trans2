KO Trans 2 — Portable ZIP

처음 사용
1. ZIP 전체를 한 폴더에 압축 해제합니다. EXE만 따로 옮기지 마세요.
2. KoTrans2.exe를 실행하고 메인 화면의 처음 사용하기를 열어 게임 프로필·영역·번역 서비스를 설정합니다.
3. 번역 시작을 누릅니다. 메인 화면의 도움말에서 단계별 화면을 확인할 수 있습니다. Python이나 .NET SDK를 별도로 설치할 필요는 없습니다.

업데이트
1. 알림 영역 아이콘 우클릭 → 종료로 완전히 종료합니다. 창의 X는 트레이로 숨깁니다.
2. 새 ZIP을 이전 프로그램과 다른 폴더에 압축 해제합니다.
3. 새 KoTrans2.exe를 실행하면 같은 Windows 계정의 기존 프로필과 설정을 사용합니다.
4. 정상 동작을 확인한 후 이전 프로그램 폴더를 삭제할 수 있습니다.
5. 캐릭터 사전 JSON을 이전 프로그램 폴더 안에 직접 두었다면 먼저 따로 보관하고 새 경로를 프로필에 지정하세요. 사용자 지정 절대 경로는 자동 변경하지 않습니다.

사용자 데이터
%LOCALAPPDATA%\KoTrans2
설정·게임 프로필·암호화된 API 키·로컬 AI 모델은 이곳에 있습니다. 업데이트할 때 삭제하거나 이동하지 마세요.
API 키는 DPAPI CurrentUser로 보호되므로 다른 PC/Windows 계정으로 이동하면 다시 등록해야 할 수 있습니다.

로컬 AI
최초 동의 후 선택한 모델(표준 약 4.6GB, 경량 약 1.1GB)을 다운로드하므로 인터넷과 여유 공간이 필요합니다.
이후에는 기존 파일을 재사용합니다. ZIP에는 대형 GGUF를 포함하지 않습니다.

이전 버전으로 복구
앱을 완전히 종료하고 %LOCALAPPDATA%\KoTrans2\settings.json을 별도 파일로 보관합니다.
Backups\settings-before-...json 중 복구 대상 버전 실행 전에 생성한 백업을 복사해 settings.json으로 이름을 바꿉니다.
이전 실행 파일을 사용합니다. 새 버전 설정을 구버전이 항상 읽을 수 있는 것은 아닙니다.
암호화된 키 파일과 Models 폴더는 그대로 둡니다. 상세한 실패·복구 설명은 USER-GUIDE.md를 참고하세요.

버전·소스 커밋·빌드 정보는 release.json, ZIP 무결성은 배포 ZIP 옆의 .sha256을 확인하세요.
새 PC/게임/그래픽 드라이버별 동작은 실제 환경 검증이 필요하며 실행 파일은 서명되지 않았을 수 있습니다.
