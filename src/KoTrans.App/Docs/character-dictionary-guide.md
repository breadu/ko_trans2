# 캐릭터 사전이란?

게임 인물의 **한국어 이름과 호칭을 일관되게 번역**하도록 AI에 알려 주는 참고 파일입니다. 게임별로 다른 JSON 파일을 지정할 수 있습니다.

## JSON 파일 만드는 방법

1. 메모장이나 VS Code에서 새 파일을 엽니다.
2. 아래 JSON 예시를 복사해 게임에 맞게 이름과 설명을 바꿉니다.
3. 파일을 **UTF-8**로 저장합니다. 파일명 예: `characters.json` (확장자 `.json`).
4. **캐릭터 사전 사용**을 켜고 **사전 선택…**으로 파일을 지정합니다.
5. **설정 저장**을 누릅니다. 오류가 표시되면 JSON 파일을 수정하세요.

**더 쉬운 방법:** AI에게 **게임 제목과 아래 JSON 예시**를 보여 주고 캐릭터 사전 작성을 부탁하세요.

예: "○○ 게임의 주요 등장인물을 아래 JSON 형식으로 정리해 줘. 공식 한국어 이름을 우선하고, 모르는 정보는 추측하지 말고 스포일러도 제외해 줘."

**확인:** AI가 만든 이름과 관계는 틀릴 수 있으니 저장 전 직접 검토하세요.

## JSON 작성 예시

```json
[
  {
    "name": "Alice",
    "korean_name": "앨리스",
    "description": "주인공의 동료. 왕국 출신 기사."
  },
  {
    "name": "佐藤",
    "korean_name": "사토",
    "description": "주인공의 선배. 차분한 말투."
  }
]
```

## 필수 항목과 주의 사항

- `name` **필수**: 게임 원문에 표시되는 이름. `korean_name` **필수**: 번역에 사용할 한국어 이름.
- `description` **선택**: 역할·관계·호칭 등 짧은 설명입니다.
- JSON은 `[ ]`로 감싼 배열이며, 이름과 문자열에는 큰따옴표를 씁니다. 마지막 항목 뒤 쉼표와 `//` 주석은 넣지 마세요.
- 파일은 **256 KB 이하**, 캐릭터는 **최대 300명**입니다. 설명은 간단하게 작성하세요.
- **Gemini·OpenAI·지원하는 Ollama Chat** 번역은 참고할 수 있지만, **DeepL·Ollama TranslateGemma**는 캐릭터 사전 지시를 지원하지 않습니다.
- **로컬 AI·Ollama HY-MT** 번역은 현재 원문에 나온 이름의 한국어 표기를 참고합니다. 인물 설명은 전달하지 않습니다. Ollama의 HY-MT 모델은 요청 방식을 **HY-MT (번역 전용 모델)**로 선택하세요.
- 원문에 없는 인물이나 설정을 만들어 넣지 않습니다. 파일 수정 후에는 번역을 다시 시작하세요. 앱에서 사전을 자동 생성하지는 않습니다.
